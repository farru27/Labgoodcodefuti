# LabCode Mobile 🚀

Editor de código para celular inspirado en la interfaz de VS Code.

## Incluye
- Explorador de archivos
- Editor HTML, CSS y JavaScript
- Pestañas de archivos
- Números de línea
- Posición del cursor
- Guardado automático en `localStorage`
- Botón Ejecutar
- Vista previa integrada
- Vista previa en nueva pestaña
- Política de privacidad
- Diseño oscuro estilo VS Code
- Interfaz adaptada a pantallas móviles

## Archivos
- `index.html`
- `style.css`
- `script.js`
- `privacy-policy/index.html`
